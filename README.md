# DevOps Portfolio Website

## Project Overview
This project demonstrates how to deploy a static website using GitHub Pages.

## Technologies Used
- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

## Features
- About Me section
- DevOps Skills section
- Projects section
- Responsive CSS styling

## Project Structure

```text
devops-task-05-github-pages/
├── index.html
├── style.css
└── README.md
```

## Live Website
https://khade-dinesh.github.io/devops-task-05-github-pages/

## Deployment Steps
1. Created a static website using HTML and CSS.
2. Pushed the project files to GitHub.
3. Enabled GitHub Pages from the repository settings.
4. Selected the `main` branch and `/ (root)` folder.
5. Verified the published website.

## Learning Outcomes
- Learned the basics of static website hosting.
- Practiced Git version control.
- Learned how to publish a website using GitHub Pages.
